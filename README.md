# Shiv Shatakshi Agro (SSA) - Corporate Web Platform

Welcome to the proprietary web application for **Shiv Shatakshi Agro**. This platform serves as the official digital storefront and product catalog, designed specifically for commercial and enterprise operations. It provides an elegant, interactive, and seamless browsing experience for our extensive inventory of agricultural solutions, including Insecticides, Herbicides, Fungicides, Bio-stimulants, and Plant Growth regulators.

## 🌾 Business Overview
**Shiv Shatakshi Agro** is dedicated to providing high-quality, innovative agricultural products that empower farmers to maximize crop yield, protect against pests and diseases, and ensure sustainable farming practices. 
- **Mission**: To deliver reliable, science-backed agricultural solutions that enhance crop health and farming efficiency.
- **Product Portfolio**: We specialize in premium agrochemicals including Insecticides, Herbicides, Fungicides, Bio Insecticides, Micronutrients, Wetting Agents, and Plant Growth Regulators.
- **Target Market**: Commercial farming operations, distributors, and individual agricultural professionals seeking top-tier crop protection and enhancement.

## 💻 Technical Platform Overview
This application is developed to meet the operational and marketing needs of Shiv Shatakshi Agro. It features:
- **Corporate UI/UX**: Built with React and Tailwind CSS for a premium, responsive, and brand-aligned design across all devices.
- **Dynamic Interactions**: Powered by Framer Motion for buttery-smooth scrolling, fade-ups, and professional page transitions.
- **Advanced Product Catalog**: Instant, zero-reload filtering of the company's product lines by category, crop type, and pest type.
- **Smart Navigation**: A responsive architecture featuring custom desktop hover-dropdowns and mobile accordion menus to streamline client access.

## 🚀 Technology Stack
- **Framework**: [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Routing**: React Router
- **Language**: TypeScript

## 🔒 Internal Developer Setup

This repository is proprietary. Authorized developers can set up the local environment using the following steps:

1. **Install dependencies:**
   Ensure [pnpm](https://pnpm.io/) is installed on your workstation.
   ```bash
   pnpm install
   ```

2. **Start the local development server:**
   ```bash
   pnpm run dev
   ```

3. **Production Build Generation:**
   Before deploying to the company's production servers, generate the optimized build bundle:
   ```bash
   pnpm run build
   ```
